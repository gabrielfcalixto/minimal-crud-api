# Minimal CRUD API

Este projeto envolve a criação de uma API minimalista com operações CRUD (Criar, Ler, Atualizar, Excluir), construída em C# com .NET Minimal APIs.

## Tecnologias

- C# / .NET
- Minimal API

## Como executar

```bash
dotnet restore
dotnet run
```
